## Raw notes (verbatim, in Josh's order)

1. For the post cards, Front: Every motion leaves a wake. Back: Track what feeds your life. [QR] Onduler. The visual on the front should be the wake and the waves from the anchors' lock screen in Biarritz dark mode. Back should be Biarritz light mode background color.
2. In Biarritz dark mode, in the bottom nav bar, change motions, swells, anchors, and settings text and icon color to #B74531. Change the + at the top right to this color also.
3. In Biarritz light mode, replace all black text with blue text (match the background color in Biarritz dark mode) and change gray text to lighter versions of that same blue.
4. Make it so the check boxes on the motion page do NOT check off the motion as complete for the day. The check boxes should just allow you to drag and drop.
5. On the motions page, make the motions drag and drop when the swells view is on.
6. On swell creation change "Swells are nouns. Your motions feed your swells. Add what you want to see in your life." to "Swells are nouns. Add things that matter to you. Motions feed swells."
7. When you click to edit a motion, add a border and box around the motion text so users know they can edit it. It should look like the number value for pts and hrs.
8. If a motion has submotions, put the caret on the right side of the motions edit button. I tried to click into the caret and accidentally marked my motion as complete.
9. On the motions page, when I am in swell view, change the text "default view" to not be highlighted.
10. On the settings page, change groups to buckets and in the description change buckets to groups.
11. For the athlete starter build and suggested swells, change Food to Nutrition.
12. For the settings page, let's have this look more like a list than a cluttered mess to fit with the rest of the app. List: appearance, starter sets, past chapters, tracking, celebration, account, data. Sign out and send feedback remain as constants at the bottom of the page even as drop downs happen.
13. On the swells page change the week progress bar's fill color to the same ombré color as the motions page progress bar's fill color.
14. Change Biarritz to be the default color scheme. Keep the name Biarritz. We are dropping default as a word. Change default name to Tjørnuvík.
15. Instead of having default view/by swell and hide done/show all, I want a filter button (shown as the common filter symbol) on the right side and a views button on the left side (shown as a calendar icon). The motions list will default to hiding checked motions, not showing swells, and showing pts and the filter will allow them to check which of these they would like to change (show completed, show swells, hide pts/hrs). If they check the views button, this will allow them to edit the week. A weekly chart will drop below each motion and they can check/uncheck a box under each day to make an edit. They can scroll backwards to edit the previous week. Submotions should come out and be listed like motions so they can be edited too. They should be listed with an indent under their parent motion.

## Triage

### Resolved this session — folded into ADR 0013

- **#4 — checkboxes don't log.** Confirmed: option (b) — checkbox is drag-only, log happens via tap on row body. See ADR 0013 §5.
- **#5 — drag motions in by-swell view.** Reinterpreted: not just reorder — full cross-swell *move* via drag. Toast pattern surfaces Undo + "Keep both" (which invokes Duplicate). Drag to Unassigned strips all swells with its own undo. Same-swell reorder stays silent. See ADR 0013 §4.
- **#8 — caret on right when submotions exist.** Falls out naturally once the checkbox stops being a log target (§5 of ADR 0013). Caret moves to right side next to the edit affordance.
- **#9 — "default view" un-highlighted in swell view.** Superseded — that toggle row is removed entirely in the header restructure. The Filter popover replaces it; the active-toggle styling problem disappears.
- **#15 — Filter / Views restructure.** The whole spec — Filter popover contents and defaults, Views week-edit mode, two-week swipe window, count-chip for multi-log days, long-press per-log delete, submotions flatten-with-indent, Add Motion in Views mode — see ADR 0013 §1–3.
- *Duplicate motion (new, not in raw notes)* — surfaced during the cross-swell drag discussion. Detail-sheet action above Delete; same name + " (copy)", same pts/hrs, empty swell links by default. The "Keep both" toast affordance is the contextual entry point. See ADR 0013 §6.
- *Toast undo pattern (new working agreement)* — generalized from the drag-between-swells affordance so future destructive-but-recoverable actions follow it consistently. See ADR 0013's PROJECT.md implications.

### Resolved this session — folded into ADR 0012

- **#10 — Groups → Buckets.** Surface word renames everywhere user-facing. Internal `groups` table stays. The "flip where it says buckets to say groups" wording resolved to: just use Bucket(s) everywhere on the surface, no more circular description. See ADR 0012.

### Polish batch (one session — atomic, no spec risk)

These are atomic UI changes that share no architectural risk. Ship together for momentum. Recommended pairing: ride along with the ADR 0013 implementation session since both touch Motions / Settings.

- **#6 — Swell creation copy.** Replace existing string with "Swells are nouns. Add things that matter to you. Motions feed swells." Tighter, matches the noun/verb teaching pattern (ADR 0002).
- **#7 — Border around motion text on edit.** Match the `border + bg-th-surface-2` treatment the pts/hrs number-input fields use. Affordance clarity — users currently can't tell the text is editable.
- **#11 — Food → Nutrition (global).** Canonical menu in PROJECT.md (line ~219), `lib/builds.ts` (Athlete preset and any other reference), onboarding swell-seed list. Single replace; Josh confirmed global, not just Athlete-context.
- **#12 — Settings as clean list.** Reorder: appearance, starter sets, past chapters, tracking, celebration, account, data. Sign out and Send feedback pinned to bottom regardless of section-expand state. Each row expands or routes; remove visual clutter.
- **#13 — Swells weekly bar ombré.** Apply the same `linear-gradient` from washed-out `--th-accent` (35% mix with `--th-surface`) to full `--th-accent` that ships on the daily progress bar. Per-swell row bars on `/swells` get the ombré; the softened weekly-aggregate bar at the top of the page stays as-is (it's the teaching bar, deliberately quiet).
