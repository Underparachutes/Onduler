What the numbers say

By reference count in the codebase, Onduler is a text-hierarchy app. The four Voice tokens (text, secondary, muted, faint) get 713 total references — more than every surface, border, and button token combined. --th-muted alone clocks 262×, the single most-used token.

The accent token shows up only 16 times. That's the philosophy: accent is loud because it's rare — kickers, links, the daily progress fill, nothing more. Same story for success, wave-wash, accent-text, and surface-2 — all sit at the floor (7×, which is just the theme definitions themselves). Worth asking whether some of those are dead weight.

The swell tokens (--th-swell-1..10) are defined but never consumed by name in component code. Swell colors come from the swells.color database column. The palette is a source for onboarding and the swell-create form to pick from — not a tokenized system the UI references. They live in a different layer than every other color in the app.

Reference count = occurrences of th-{token} in app/** and lib/** (.tsx, .ts, .css). Includes both CSS variable definitions and Tailwind utility uses (text-th-muted, bg-th-bg, etc.). Bar lengths are scaled to --th-muted = 100%.
