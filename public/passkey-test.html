Passkey PRF spike

Throwaway test: does this device return a stable secret from the WebAuthn prf extension? That secret is what would unlock the encryption key. Delete this file when done.

Step 1 — register a passkey

Creates a platform passkey (Face ID / fingerprint) and checks whether prf is supported.

Step 2 — read the PRF secret twice

Reads the secret with the same input twice. They must match for this to be usable. Works standalone — on a second device it offers your synced passkey, so you can compare the hex across devices.
